# 五项方法回看

围绕视频的五项技巧回看报告，将改动落实到相关页面。

| 方法 | 回看的问题 | 对应改法 |
|---|---|---|
| 数据背景 | 主要数字与什么比较？比较后讲出了什么变化？ | 将历史值、同类对象或行业水平放到主要数字旁边，突出最值得讲的差异。 |
| SCQA | 情景与冲突提出了什么问题？正文怎样回答它？ | 把开篇串成情景、冲突和问题，让后续各部分围绕这一问题展开。 |
| 金字塔原理 | 读者何时看到主要观点？后面有哪些关键理由？ | 将答案前置，随后展开关键发现和分析。 |
| 颜色编码 | 每种颜色对应什么？读者怎样沿颜色阅读？ | 用颜色表达分组、同类比较和文字路径，让相关信息使用稳定的对应关系。 |
| 表格与图表 | 读者需要比较大小、看趋势，还是查精确值？ | 按任务选择条形图、簇状图、堆积图、折线图或表格。 |
