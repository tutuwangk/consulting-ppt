# 快速阅读回看

打开实际渲染页面，先用约十秒查看本页，再回答“本页结论是什么、关键差距在哪里”。围绕页面承担的任务调整主图、标题和标签。

| 回看对象 | 观察阅读效果 | 修改动作 |
|---|---|---|
| 整稿故事 | 连读标题后能说出问题、答案与关键理由 | 重排跳跃的部分，合并重复论点。 |
| 标题 | 一眼读到主要观点，主体有充足空间 | 压缩重复背景与长词组，按短语含义安排断行。 |
| 核心比较 | 迅速看到决定选择的差距 | 用位置、长度、颜色或直接标注突出这项关系。 |
| 情景差异 | 看到不同结果，尤其是低于预期时的表现 | 将各情景放到同一个比较结构中，突出收益差距与关键门槛。 |
| 数字 | 能快速读懂量级、变化和重要阈值 | 统一单位与精度，将次要明细移到辅助表或备注。 |
| 阅读路径 | 先看到主要观点，再进入对应图形和细节 | 调整面积、字重、标签位置和分组。 |
| 行动页面 | 找到下一步动作及对应责任人 | 将动作、条件与责任人放到相邻位置。 |

对关键页并排查看备选构图，选择读者更快理解的一种。修改后重新查看该页，并连读相邻页标题，完成内容与视觉之间的调整。
